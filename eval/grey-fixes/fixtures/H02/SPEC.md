# New contacts CSV export
Add the export feature in contacts.py. export(rows) returns UTF-8-compatible CSV text with columns name,note in that order, a header and final newline. Each row contains two arbitrary strings, including empty strings and Unicode; retain their exact values and input order without mutating rows. Valid CSV encodings that parse to the same two fields are equivalent. Empty input is header-only. python3 contacts.py reads contacts.json and writes contacts.csv using export. Deliver the real CSV and source that reproduces it. No dependencies. Existing tests, contacts.json, this spec and .gitignore stay byte-identical; additive tests go in new files.
