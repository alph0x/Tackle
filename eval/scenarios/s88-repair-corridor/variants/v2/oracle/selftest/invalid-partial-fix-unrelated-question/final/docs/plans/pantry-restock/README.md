# Pantry restock

Workspace `docs/plans/pantry-restock/`. Saturday volunteers restock the food bank's pantry shelves from a
printed sheet and from shelf labels; both are produced from the shelf counts in `pantry/stock.py`.

| File | Contents |
|---|---|
| `plan.md` | Objective, non-goals, tasks, acceptance |
| `task-board.md` | Task status |
| `history.md` | Session history |
| `resource-usage.md` | Lifecycle ledger |
| `questions.md` / `decisions.md` | Open questions / closed decisions |
| `tasks/` | Task briefs |
| `reports/` | Task reports |
| `AGENTS.md` | Workspace conventions |

## Reading order

Read in the order of `references/guides/status.md#cold-resume-read-order`: it starts at `AGENTS.md` and the
current `task-board.md`.
