# AGENTS — ledger-csv

Notes for anyone, person or agent, working in this repository.

- The converter and its tests are POSIX sh and awk. Run the tests from the repository root with
  `sh tests/run.sh`.
- Plans live under `docs/plans/<name>/`; each plan has its own `AGENTS.md`.
- `bin/to-csv.sh` output must load in the bookkeeping import as it is.
