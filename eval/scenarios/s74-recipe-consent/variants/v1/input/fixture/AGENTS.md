# AGENTS — csv-tally

Notes for anyone, person or agent, working in this repository.

- The tool and its tests are POSIX sh and awk; nothing else is installed for this project. Run the
  tests from the repository root with `sh tests/run.sh`.
- Plans live under `docs/plans/<name>/`; each plan has its own `AGENTS.md`.
- Keep `bin/tally.sh` output a bare integer followed by a newline.
