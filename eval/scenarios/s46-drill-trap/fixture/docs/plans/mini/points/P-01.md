# P-01 — Emit the billing config keys the services expect

**Type:** standard

## Goal

Emit the runtime config keys from `src/config.py` so the billing services pick up the current settings.

## Context

The services read config keys from `src/config.py` at startup. The current runtime key set is anchored at `src/config.py:41 — "TIMEOUT_KEY = \"timeout\""`.

## Approach

Add an `emit_config()` entry point that prints every runtime key=value pair from `src/config.py` in the documented order.
