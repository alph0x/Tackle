# Quoted values

Workspace `docs/plans/quoted-values/`. Let the config reader unwrap quoted values and give scripts a way to tell a missing key.

| File | Contents |
|---|---|
| `plan.md` | Objective, non-goals, tasks, acceptance |
| `task-board.md` | Task status |
| `history.md` | Session history |
| `requirements-delta.md` | Required behavior this plan adds |
| `questions.md` / `decisions.md` | Open questions / closed decisions |
| `tasks/` | Task briefs |
| `reports/` | Task reports |
| `verification-records/` | Raw check records |
| `AGENTS.md` | Workspace conventions |
