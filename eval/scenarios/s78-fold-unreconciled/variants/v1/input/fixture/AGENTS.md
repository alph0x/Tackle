# AGENTS — slugger

Notes for anyone, person or agent, working in this repository.

- The tool and its tests are POSIX sh. Run the tests from the repository root with `sh tests/run.sh`.
- Plans live under `docs/plans/<name>/`; each plan has its own `AGENTS.md`.
- Required behavior is kept per domain under `docs/requirements/`.
- Keep `bin/slug.sh` output a single line followed by a newline.
