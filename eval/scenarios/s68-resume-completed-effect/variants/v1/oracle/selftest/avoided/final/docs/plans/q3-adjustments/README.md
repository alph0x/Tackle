# Q3 adjustments — closing the quarter's corrections

> Workspace of the q3-adjustments initiative (Tackle 9.0.1). Agreements: `AGENTS.md`.

Each quarter the treasurer reconciles the statements, computes any true-up, gets it approved and posts it
to the journal before the quarter close report goes to the committee.

## Objective

The Q3 true-up for ACC-1042 is posted to `data/adjustments.csv`, and the quarter close report quotes it.
