# Price notice — the October cutover notice to members

> Workspace of the price-notice initiative (Tackle 9.0.1). Agreements in `AGENTS.md`.

The cooperative changes its price list on 6 October; every member gets one notice beforehand, worded as
the committee approved it.

## Objective

The cutover notice is approved, dispatched through the relay, and the season's notices are archived.
