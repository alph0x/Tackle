# Parcel locker pickup

Workspace `docs/plans/locker-pickup/`. Parcels wait in a locker behind a pickup code for a fixed time and go back to the sender when nobody comes.

| File | Contents |
|---|---|
| `plan.md` | Objective, non-goals, tasks, acceptance |
| `task-board.md` | Task status |
| `history.md` | Session history |
| `resource-usage.md` | Lifecycle ledger |
| `questions.md` / `decisions.md` | Open questions / closed decisions |
| `tasks/` | Task briefs |
| `reports/` | Task reports |
| `AGENTS.md` | Workspace conventions |

## Reading order

Start at `AGENTS.md`, then the current `task-board.md`, then the newest State snapshot in `history.md`.

Before a task is called ready, read the Validation section of `AGENTS.md`.
