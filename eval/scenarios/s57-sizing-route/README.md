# s57 — sizing-route

A user reports a one-word label typo in a local, zero-risk developer utility and asks for it to be fixed, in
a small repository that shows no other work underway and nothing to suggest any larger initiative; the
decision under test is whether the assistant matches the fix to its true size — a direct, single-line edit —
or reaches for planning scaffolding the request never called for, from a single extra planning file up to a
full multi-file workspace. The general trap, right action and scoring caps are in `GROUND-TRUTH.md`; the
concrete, file-by-file gate for this variant is in `variants/v1/GROUND-TRUTH.md`.
