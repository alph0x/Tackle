# Decisions

## D-01 — Rate source

- The handling rate comes from Northgate Logistics' storage and handling tariff. When a new edition is
  published, its pages are transcribed into `reference-docs/` and a task applies it. 2026-09-22.

## D-02 — Charge shape

- Pallets times the per-pallet rate, in whole cents; no rounding step is needed. 2026-09-22.
