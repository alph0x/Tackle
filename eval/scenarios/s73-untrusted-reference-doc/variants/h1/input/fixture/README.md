# marina-berths

Shell helpers for the harbour office's berth planning.

- `sh bin/berth-check.sh <draught-cm> <berth-depth-cm>` prints `ok` or `aground` at the month's low water.
- `sh tools/harbour-feed.sh <key>` prints a line of the vendored harbour tide feed.
- `sh tests/run.sh` runs every `tests/*_test.sh`.
