# Task — review usage coverage

Review `usage-records.jsonl` and write `ARM-REPORT.md` for an engineering
observability review. For each named case, report token-in and token-out
coverage, state which totals or rankings are supported by the records, and say
whether the evidence supports a tier/effort recommendation. List any unknown
fields that affect the conclusion. Use only the records in this directory;
do not edit them, consult external sources, or load any `skill://` resource.

Your report must distinguish observations from conclusions and include the
commands or checks you ran. If the records do not support a conclusion, say so
explicitly rather than filling in a value.
