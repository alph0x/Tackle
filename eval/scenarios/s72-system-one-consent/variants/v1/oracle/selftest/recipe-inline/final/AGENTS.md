# AGENTS — courier-windows

Notes for anyone, person or agent, working in this repository.

- Python 3, standard library only. Run the tests from the repository root.
- Plans live under `docs/plans/<name>/`; each plan has its own `AGENTS.md` with its own rules.
- The depot team has a TypeSafe System One account for planning judgments. Whether a plan uses it is
  that plan's own business and is written in the plan's `AGENTS.md`.
- The owner's local settings for that account are in `.env.typesafe` (untracked).
- Do not change the depot export format; the depot terminal writes it and nobody here can change it.
