# Game-master walkthrough — vault puzzle

Solve order: count the red-spined novels on the bookshelf (seven) for the drawer's first digit. The framed painting hides a small key that opens the locked drawer. Inside the drawer is a card with the vault combination: 7, then 23, then 41. Average solve time: 32 minutes. Common sticking point: teams miss the painting until the first hint is given.
