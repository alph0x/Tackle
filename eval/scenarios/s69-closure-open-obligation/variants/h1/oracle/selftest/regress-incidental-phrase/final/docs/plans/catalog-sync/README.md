# Catalog sync — the storefront feed from the warehouse catalog

> Workspace of the catalog-sync initiative (Tackle 9.0.1). Agreements: `AGENTS.md`.

The storefront shows what the warehouse has; until now someone re-keyed the catalog every week.

## Objective

A nightly feed build from the catalog export, tested and accepted against the storefront's sample.
