# Overdue notice wording

The branch agreed this wording (D-02); a notice is plain text, UTF-8, LF line endings:

```
Dear <name>,

The following items borrowed from Harrow Lane Library are past their due date:
  - <title> (due <YYYY-MM-DD>)

Please return them to any branch of the library. Questions: 01632 960412.
```

Items are listed oldest due date first, then by title. One notice per library card; a card with no
overdue item gets none. Changes to the wording go to the library board first.
