# Fee statement layout

One statement per plot, in register order, separated by a blank line. Each statement has five lines:

| Line | Content |
|---|---|
| `heading` | `Larkfield Allotment Society — <season> season` |
| `plot` | plot number and holder, joined by ` · ` |
| `fee` | `Plot fee (<n> rods): £x.xx`, at the rate per rod in force (D-03) |
| `water` | `Water: £x.xx`, the flat charge where a tap is fitted, otherwise £0.00 |
| `total` | `Total due: £x.xx`, the fee plus water |

UTF-8, LF line endings. The posted statements and the printed copy kept at the hut are the same text.
