# Shift reminders — the week's volunteer reminders from the rota

> Workspace of the shift-reminders initiative (Tackle 9.0.1). Agreements: `AGENTS.md`.

Every Thursday the volunteer coordinator wrote one reminder per shift by hand from the rota spreadsheet;
volunteers missed shifts when a reminder was late or carried the wrong time.

## Objective

`python3 -m reminders week <shifts.csv> <out.txt>` writes the week's reminders in the agreed wording,
documented and accepted.
